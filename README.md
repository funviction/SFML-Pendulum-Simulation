# Моделювання фізичних процесів за допомогою SFML (Лабораторна робота №5)

Проєкт містить реалізацію двох варіантів чисельного моделювання математичного маятника з використанням C++17, графічної бібліотеки SFML 3.0 та системи збирання CMake.

## Структура репозиторію
- **Variant_20**: Стандартна симуляція маятника з можливістю зміни параметрів (довжина підвісу, початковий кут) у реальному часі. Використовується напівнеявний метод Ейлера.
- **Variant_34**: Дослідницька симуляція. Демонструє розбіжність результатів чисельного інтегрування та втрату механічної енергії при використанні явного методу Ейлера у порівнянні зі стабільним методом Рунге-Кутти 4-го порядку (RK4).

## Вимоги до робочого середовища
- Visual Studio 2022 (з підтримкою C++ Desktop Development).
- Пакетний менеджер vcpkg.
- CMake (мінімальна версія 3.20).

## Інструкція зі збирання
1. Клонувати репозиторій:
   `git clone https://github.com/[Твій_Логін]/SFML-Pendulum-Simulation.git`
2. Відкрити папку потрібного варіанта (наприклад, `Variant_20`) через **File -> Open -> Folder...** у Visual Studio.
3. Дочекатися автоматичної конфігурації CMake (менеджер `vcpkg` самостійно завантажить необхідні бінарні файли SFML за маніфестом).
4. Виконати збирання: **Build -> Build All**.
5. Обрати `.exe` файл як ціль запуску та розпочати симуляцію.

## Керування симуляцією
- **Space** - Пауза / Продовження
- **R** - Перезапуск моделі з початкових умов
- **Up/Down** - Зміна довжини підвісу (тільки для Варіанта 20)
- **Left/Right** - Зміна початкового кута (тільки для Варіанта 20)
